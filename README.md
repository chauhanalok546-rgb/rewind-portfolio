# Rewind: The Alok Timeline

**Live site: https://rewind-ten-psi.vercel.app**

An interactive, voice-led portfolio. A digital twin of Alok Chauhan greets you in a time-travel lab, asks if you want to travel back through his life, then narrates six scenes in his own recorded voice: Uttarkashi (2015), MDS Uttarkashi (2023 to 2024), Dehradun (2024 to 2026), NST Pune (2026), the future, and back to the present.

Built for the Wispr Flow "Wispr Your Way into Wispr Flow" challenge. Every instruction to the AI that built it was dictated with Wispr Flow.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
```

Developer shortcuts (URL hash): `#dev` (expressions, gestures, camera), `#lobby`, `#ask`, `#transition`, `#film-scene0` to `#film-scene6` (the film from that scene; sound needs one click first).

## How it works

| Part | Where |
| --- | --- |
| 3D stage (lights, platform, rings, teleport dissolve, adaptive resolution) | `src/stage.ts` |
| Avatar runtime (idle life, blink, look-at, 52 ARKit + 15 viseme morph targets, expressions, gestures, audio-driven lip-sync) | `src/avatar/Avatar.ts` |
| Experience state machine (boot, enter, greeting, Yes/No popup, snap and flash) | `src/app/app.ts` |
| The film (one GSAP master timeline, 7 scenes, time tunnel) | `src/film/` |
| Narration (34 lines in an AI neural voice, captions, gestures) | `src/voice/Narrator.ts`, `public/audio/narration/` |
| Synthesised sound effects and music beds | `src/audio/` |
| Avatar build scripts (Blender, Avaturn export to final GLB) | `blender/scripts/` |
| Recording tools | `tools/record.html`, `tools/review.html`, `scripts/ingest_voice.py` |

The whole film runs without any API calls: narration is static audio, lip-sync is driven by the audio itself.

## The voice

The narration is spoken by an AI voice (Microsoft neural voice `en-IN-PrabhatNeural` for Alok's twin, `en-GB-RyanNeural` with a radio filter for ARM-01), generated by `scripts/generate_ai_voice.py` (uses the `edge-tts` package; no account or key). Alok's own recordings are kept in `reference/voice-alok-recorded/` and can be put back, or any single line re-recorded with `tools/record.html` and `scripts/ingest_voice.py`.

## Keyboard and voice

Space play/pause, Left/Right previous/next scene, R replay, C captions, S sound, M microphone, Esc closes the popup.

Voice (Chrome and Edge; needs the microphone): say "yes" or "no" at the popup, then "pause", "play", "skip" or "next", "back" or "previous", "replay", "contact", "show me" (scene 5), or a year such as "2015" or "twenty twenty six". Only short, whole phrases count, so the avatar's own sentences can never trigger a command. The parser is tested: `node --test tests/parse.test.ts`.

## Camera

If you allow it, the camera is used only to notice that a face is present (MediaPipe runs on your device, nothing is stored or sent) and is switched off as soon as the greeting starts. Decline it and the avatar greets you right away.

## Privacy

Camera: only to notice a face, on-device, off after the greeting. Microphone: only to hear short commands, while the mic icon is lit; the browser's speech service handles recognition. Nothing is recorded or uploaded by this site.
